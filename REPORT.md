# Chess Trainer — Отчёт по проекту

## Введение

Проект представляет собой шахматный тренажёр с клиент-серверной архитектурой. 
Состоит из двух частей:

1. **Клиент (Pygame)** — графический интерфейс для игры и тренировки
2. **Сервер (FastAPI + SQLite)** — хранение данных, бизнес-логика

Пользователь играет в шахматы против Stockfish или легендарных шахматистов, 
решает задачи с Lichess, а все партии автоматически сохраняются на сервере 
в базе данных для последующего анализа.

### Клиент-серверное взаимодействие

Клиент (игра) не хранит данные локально — вся информация отправляется на сервер.
Когда партия заканчивается, игра делает HTTP POST-запрос на `/api/v1/games`,
и сервер сохраняет её в БД SQLite.

Сервер предоставляет REST API:
- Хранение партий пользователей
- Статистика (сколько игр, топ соперников)
- Генерация игр — выдача случайной партии из архива
- Управление пользователями и событиями

## Функциональность

### Шахматный тренажёр (Pygame)

**Режимы:**
- **Puzzle Training** — 300 задач из базы Lichess (локально)
- **Online Puzzles (Lichess API)** — бесконечные задачи с сервера Lichess
- **Play vs Stockfish** — 4 уровня сложности (ELO 1320–2500)
- **Play vs Legends** — 6 великих шахматистов с реальными пиковыми рейтингами

**Игровая механика:**
- Правила шахмат через `python-chess`
- Плавные анимации движения фигур
- Взятие с эффектом исчезновения
- Подсветка последнего хода и шаха
- Eval bar (оценка позиции)
- Материальный счёт
- История ходов с прокруткой
- Таймеры с инкрементом
- Управление стрелками правой кнопкой мыши
- Переворот доски

**Звуки:**
- 7 звуков сгенерированы программно (без внешних файлов)
- Ход, взятие, шах, победа, поражение, правильный/неправильный ход

## Интеграция с Lichess API

Для получения свежих задач используется **открытый API Lichess**:
GET https://lichess.org/api/puzzle/next

Возвращает JSON с задачей:
- **FEN** — позиция на доске
- **solution** — список правильных ходов
- **rating** — сложность задачи
- **themes** — теги (mateIn2, fork, pin, endgame и т.д.)

Задача парсится из PGN, извлекается позиция и решение. Игрок решает задачу, 
программа проверяет ход.

**Преимущества:**
- Задачи никогда не закончатся (миллионы на сервере)
- Всегда свежие
- Адаптивный рейтинг
- Показ тегов (что тренирует игрок)

## Технические решения

### Многопоточность
Stockfish работает в отдельном потоке. Игра не зависает пока движок думает.

### Очередь `queue`
Результаты AI передаются в главный поток через `queue.Queue` — защита от race condition.

### Pydantic валидация
Все входные данные проверяются Pydantic-моделями (`GameCreate`, `UserCreate`, `EventCreate`).

### Swagger /docs
Автогенерация документации из кода через OpenAPI.

### Тесты pytest
9 тестов на бизнес-логику:
- Проверка `/health`, `/`, `/stats`
- Создание партий, юзеров, событий
- Обработка ошибок 404

## Сложности и решения

### 1. Зависания при ходах AI
**Проблема:** Stockfish думал 0.5-1 секунду и блокировал главный цикл.
**Решение:** Вынес AI в отдельный поток, общение через `queue`.

### 2. Кириллица в pygame
**Проблема:** Pygame не рендерит русские буквы стандартным шрифтом.
**Решение:** Перевёл интерфейс на английский + использовал `SysFont("Segoe UI")`.

### 3. Двойное нажатие в puzzle
**Проблема:** Игра отправляла партию на сервер 60 раз в секунду.
**Решение:** Флаг `_last_saved_game_token` — сохраняет только один раз.

### 4. Битые задачи в CSV
**Проблема:** Некоторые FEN не валидны, `chess.Move` падал.
**Решение:** Валидация при загрузке — пропуск плохих записей.
